Marauder Mini v3 · ESP32-C5

Firmware flasher for Cyberpunk Edition

Flashes the neon-rethemed, 128 px text-fitting build of ESP32 Marauder straight from your browser. No toolchain, no drivers, no command line — the page talks to the board over USB.

Built on ESP32 Marauder v1.17.0 by justcallmekoko — see the repository for the full change list, the source, and the licence.

What this build changes

  • MAC addresses are no longer cut off. Lines longer than the 21 characters the 128 px panel can show wrap onto the row below instead of being clipped, so "BSSID: AA:BB:CC:DD:EE:FF" is readable in full.
  • Follow / device list shows the whole address rather than only the second half of it.
  • Long screen titles fit. Titles drawn in the large font drop to the small font when they would overrun the panel.
  • GPS screens read in full. The date/time and UTC stamps were being cut off mid-string; every GPS line wraps now, and so do the 60–80 character NMEA sentences on the raw NMEA screen.
  • Color that means something. Menus color by what an item is — tags one color, Bluetooth another, passive monitors another — with a floor of 35° of hue between any two colors in the same menu, so no submenu reads as one flat color. The attack menus are grouped by mechanism: beacon spam, floods and disruption, and rogue-AP or social attacks. On data screens the field name is dimmed and the value is colored by its kind, so a screen of readings can be skimmed by shape.
  • New boot screen: the Marauder mark, tinted down its height from the theme's accent cyan into hot magenta, over the CYBERPUNK EDITION wordmark and the version.
  • Neon cyberpunk palette derived from a reference image, on black with a deep indigo status bar. Every color is checked against a contrast floor by the generator, so no text is left unreadable.
  • Screen brightness is adjustable: Device > Brightness. Up/right brightens, down/left dims, centre saves. The level persists.
  • Status bar shows more: GPS in three states — no module, no fix yet, or a fix — and SD green or red.

Nothing else was changed. Every tweak is gated on the Mini v3 target: on every other board each color name resolves to the stock value, so no other board's colors or behaviour change. The flash layout is byte-identical to the official v1.17.0 Mini v3 release.

Flash it

Application updatekeeps your settings

Writes the firmware into the application slot at 0x10000 and points the OTA data at it. Your saved preferences, WiGLE / WDG credentials, Evil Portal templates and logs are left alone. Use this one.

Chrome or Edge on desktop. Nothing appears? Check the requirements below.

Full installerases settings

Writes the bootloader, partition table, OTA data and application. Use this for a blank board, or if an update will not boot. This one replaces everything on the flash, including stored settings and logs.

How to do it

  1. Use Chrome or Edge on a desktop — Firefox and Safari cannot talk to USB serial.
  2. This page is served over https://, which is what Web Serial requires. Nothing to install.
  3. Plug the Mini v3 in with a data-capable USB-C cable.
  4. Click an install button and pick the board's serial port. It usually shows up as USB JTAG/serial debug unit or USB Serial Device.
  5. If no port appears, unplug, then hold BOOT while plugging it back in to force download mode.
  6. Wait for 100%, then the board reboots on its own. If it stays dark, press the reset button.

Other ways to flash

The merged single-file image in firmware/ can be written at offset 0x0 with Espressif's Flash Download Tool, or with esptool: 

esptool.py --chip esp32c5 --port /dev/cu.usbmodemXXXX write_flash 0x0 \
  firmware/marauder-mini-v3-*-factory-8MB.bin

To go back to the stock firmware, flash the official v1.17.0 Mini v3 release with the same method.
